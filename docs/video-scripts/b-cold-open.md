# Version B — Cold open (~1:45)

Opens on the product feeling, not an explanation: **taps → silence → eyes open → title**. Then the problem, you, how it works, iPhone, Pro and the ending.
This version shows why AtLeast exists before saying it, so a judge gets the idea in the first 10 seconds without any voiceover.

## Why this order

- **The opening needs no words** and works with the sound off, which matters for autoplay on YouTube and in the Devpost gallery.
- **The alarm-and-plank beat comes second,** so it plays as a contrast to the calm opening.
- **The silence callback before the end card** closes the loop, and it's where the swappable ending starts.
- **The paywall is reached from History here.** A uses Save and C shows all the triggers, so you film every path at least once.
